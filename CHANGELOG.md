# Changelog

## 0.1.0 (2026-10-27)

First release: a table-popover and toolbar button that opens a dialog for the
table the cursor is in, its row and its cell: width, border and border color,
backgrounds, alignment, vertical alignment, padding, a header row (th with
scope="col"), and cell settings applied to every cell. Only the fields changed
are applied. Translatable strings, its own icon, ids unique per editor.
